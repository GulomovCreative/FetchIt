# Тексты страниц для маркетплейсов

Содержимое карточек FetchIt для [modstore.pro](https://modstore.pro/packages/utilities/fetchit)
и [extras.modx.com](https://extras.modx.com/package/fetchit). Файлы разбиты на блоки
`## Поле: …` / `## Field: …` — они соответствуют полям формы площадки, текст копируется
целиком, без правки.

| Площадка | Русский | English |
|----------|---------|---------|
| modstore.pro | [`modstore.ru.md`](modstore.ru.md) | [`modstore.en.md`](modstore.en.md) |
| extras.modx.com | [`extras.ru.md`](extras.ru.md) | [`extras.en.md`](extras.en.md) |

Порядок загрузки и то, что уже сделано, — в [`upload.md`](upload.md).

## Формат описания

**modstore.pro принимает HTML, а не markdown.** Поэтому рядом с каждым `modstore.*.md`
лежит `modstore.*.description.html` — раздел «Полное описание», готовый к вставке в форму:

```sh
node marketplace/build.mjs
```

Markdown остаётся источником: правьте `.md`, затем пересоздавайте `.html`. Редактор
описания на modstore — тот же, что у заметок modx.pro, и правила у него те же:

- **Абзац — обычный текст**, абзацы разделяются пустой строкой. `<p>` не нужен: каждый
  перевод строки редактор и так превращает в `<br>`, и с `<p>` получается двойной отступ.
- **Списки** — `<ul>`/`<ol>` одной строкой, без переносов внутри.
- **Код** — `<pre class="notranslate">` **без вложенного `<code>`**: вложенный тег редактор
  экранирует, и в плашке видно `<code>` текстом.
- **Инлайновый код — `<kbd>`.** Свой `<code>` посреди предложения редактор превращает в
  `<pre>`, то есть в плашку во всю ширину. `<kbd>` он ставит сам, когда встречает инлайновый
  код, поэтому этот тег он и принимает. Если вдруг и `<kbd>` окажется блоком —
  `node marketplace/build.mjs --plain` соберёт описание без тегов вокруг кода.

Строки-заметки (начинаются с `>`) в описание не попадают.

extras.modx.com принимает обычный текст с абзацами — там html не нужен.

## Картинки

Картинки в описании modstore подключаются ссылками на file.modx.pro, куда они уже
загружены; соответствие «файл → адрес» — в [`urls.json`](urls.json). Исходники — в
`docs/images/`, их пересоздаёт `npm run screenshots`.

Логотип и скриншоты в форму загружаются файлами, а не ссылками:

- логотип — `.github/logo/modstore@2x.png` (640×480), рядом `modstore.png` (320×240),
  их делает `npm run logo`;
- скриншоты — файлы из `docs/images/`.
